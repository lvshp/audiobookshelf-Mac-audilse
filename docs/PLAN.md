# Audisle 技术范围

已获用户授权：源码可用、非商业使用免费，Apple Music 风格，macOS14+，Swift 原生，服务端2.26+，全功能对齐2.37.1，暂不做Chromecast。第一交付必须包含听书和离线闭环。

窗口使用原生红黄绿按钮；关闭主窗口仅隐藏窗口并持续后台播放。系统菜单栏常驻图标，提供播放/暂停、跳转、倍速、停止同步、重新打开主窗口和显式退出。显式退出等待最后进度持久化。

## 交付顺序

1. 工程、登录/JWT/OIDC、多服务器、书库/搜索/详情、音频时间轴/章节/书签/倍速/睡眠、媒体控制、下载/离线/重启/同步。
2. 作者/系列/集合/播放列表、播客/OPML/服务器下载、统计历史、EPUB/PDF/CBR/CBZ与MOBI/AZW3基础阅读、发送阅读器、RSS/分享/个人设置。
3. 原生内容管理：上传/批量、书库/扫描、匹配/封面/章节/音轨/问题文件/M4B/嵌入；原生服务器管理：用户权限、会话/API Key、备份/恢复/日志/任务/缓存/通知/SMTP/OIDC/设置。
4. 完整功能矩阵、版本兼容测试、独立审查、性能/无障碍/视觉、项目许可证及第三方声明、本机可运行应用包及安装/使用文档。

## 技术约定

SwiftUI+AppKit；URLSession/actors；GRDB 7.11.1；Socket.IO Swift 16.1.1；AVFoundation与固定VLCKit3.7.3（仅本地兼容）；EPUB.js固定版本、PDFKit、libarchive。

数据库按服务器UUID与用户ID分区。按用户最新要求不使用钥匙串。JWT access/refresh按账户使用AES-GCM加密、原子写入本地凭据文件；本机密钥与文件权限保护访问，刷新single-flight。登录密码不持久保存。兼容子路径和OIDC自有回调 shelfmac://oauth。细粒度权限决定入口，服务端仍执行权限检查。

离线下载原件。会话ID/原始时间/实际听时持久保存，同ID合并最新快照串行上传，每媒体最新先上传。服务端/session/local同时写历史与进度；双端冲突暂停该媒体上传、让用户选择位置，上传后恢复选择位置并重新核验。不要取最大进度，不要把重试时间当会话更新时间。音频与阅读共用MediaProgress。

EPUB保持start.cfi/end.percentage；PDF/漫画1起始页，进度(page-1)/numPages，漫画自然数字排序。MOBI/AZW3仅基础阅读，不伪造服务端跨端进度。

## 验证边界

至少构建Debug/Release、核心单元测试、原生UI验收、隔离2.26.0/2.36.1/2.37.1服务端；破坏性写入/删除/恢复只在隔离测试数据进行。用户已授权使用其2.37.1服务器进行登录、读取、播放与下载联调，凭据不写入仓库、文档或诊断输出。按用户2026-10-14要求，Developer ID正式签名、Apple公证及相关发布流程不纳入实施和验收，仅保留安装说明；本机运行所需的临时签名与包完整性检查保留。

性能设计采用分页、惰性网格、缩略图缓存和后台解码下载。M1/8GB、万条缓存、启动2秒及100ms反馈未实测，当前验证边界见 STATUS.md。

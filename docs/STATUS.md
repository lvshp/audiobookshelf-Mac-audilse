# Audisle 当前状态

更新：2026-10-19。当前本地交付版本为 0.1.0（build 3），Apple Silicon / macOS 14+。2026-10-17 已按用户确认范围完成交付验收；这不代表所有设备和性能指标均已实测。

## 已交付范围

Swift 原生客户端，包含账户与书库、音频播放、下载、离线重启续播与回网同步、电子书阅读、播客订阅与服务器下载、内容及服务器管理、简体中文和英文界面。技术范围见 [计划](PLAN.md)，使用和构建见 [README](../README.md)。

## 已知待改进

- 播客服务器下载队列目前需要手动刷新，尚未实现页面自动更新。
- 播客目录的 Explicit 标签中文“限制内容”容易误解，待调整为明确的内容提示。
- 空播客的详情缺少首次选集下载引导，订阅并不等于下载历史单集。

## 验证边界

- macOS 14 实机/虚拟机、M1/8GB 设备、万条缓存与精确启动/响应时延未验证，按用户要求不作为交付门槛。
- 跨年度切换、外部 HTTPS OIDC 和通知服务实连按用户要求免验；功能保留。
- 邮件收件及控制中心播放/暂停/快进/快退已由用户确认。
- 不包含 Chromecast、Developer ID 正式签名、Apple 公证或公开发布。

## 2026-10-19 播放修复

已捕获原生 HLS 播放大量分片404，以及缓冲后无声继续计时、章节跳转超时。固定 ABS v2.37.1 源码核对表明：完整VOD清单会先于按需转码分片发布，缺失分片返回404；远近分片请求可能改变转码位置。

新增仅监听127.0.0.1、随机路径的本机HLS桥接，串行获取并有界重试分片；章节跳转先取消旧请求，再按目标片裁剪清单并映射绝对时间。重试耗尽会暂停计时并显示错误。84项播放回归与Release构建通过，独立审查已执行；已在同服务器同书验证章节启动、跳至远章节及返回，用户明确确认声音正常；修复版原生播放日志的系统分片404和跳片计数为0。未进行全天或所有网络环境验证。详细证据仅本地保存于build/release-evidence/hls-playback-20261019。
